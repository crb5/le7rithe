التغييرات والأسباب

  • فصل فعلي لصفحات البائع والحساب والمحفوظات والدعم والإضافة والإدارة والصفحات الثانوية، باستخدام lazy/Suspense. الرئيسية مباشرة، والباقي عند فتحه.
  • نقل واجهات تسجيل الدخول وإنشاء الحساب وCSS وترجمات Clerk إلى تحميل عند الحاجة.
  • إزالة انتظار جاهزية Clerk من العرض العام ومن طلب الرمز للاستعلامات العامة. مزود الرمز يسجل قبل الاستعلامات المحمية، ولا يعاد تركيب الصفحة العامة عند اكتمال تهيئة Clerk، حفاظًا على البحث وحركة الظهور.
  • خط نص محلي واحد IBM Plex Sans Arabic بصيغة WOFF2 بأوزان 400/600/700، مع مجموعتي محارف عربية ولاتينية، preload لوزن عنوان الصفحة وfont-display: swap؛ إزالة CSS وروابط خطوط Google الخارجية.
  • تصغير CSS وتجهيز خادم الإنتاج بضغط Brotli/gzip. Vary: Accept-Encoding؛ كاش سنة للأصول ذات بصمة الاسم: public, max-age=31536000, immutable، وHTML no-cache. لم يتغير كاش API أو الصور الخاصة.

الأسباب الأساسية كانت انتظار SDK مصادقة لمحتوى عام، والاستيراد المباشر لكود صفحات غير مطلوبة، وسلاسل CSS/خطوط خارجية، وحجم نقل محلي غير مضغوط. القياس يعكس التعديلات مجتمعة، لا تجربة منفصلة تنسب زمنًا دقيقًا لكل سبب.

التحقق

  • نجح TypeScript و35 اختبارًا محليًا.
  • ظهر المحتوى العام وتفاصيل الإعلان الحقيقي أثناء تأخير Clerk نحو 20 ثانية؛ الصفحات المحمية لم تعرض بيانات أو نماذج ولم تطلب APIs محمية.
  • نجحت إعادة التوجيه للدخول للمستخدم غير المسجل، وبقيت مطالبة الحساب قبل النشر.
  • نجحت نماذج الدخول والتسجيل العربية وتبديل الفرنسية والإنجليزية والتنقل العام، دون تجاوز أفقي عند 390 px.
  • أكدت طلبات HTTP خادم الإنتاج المحلي: ضغط br وgzip، كاش الأصول المرقّمة، HTML no-cache و404 حقيقي للأصول المفقودة.
  • لم تنشأ حسابات أو إعلانات أو دفعات أو رسائل أو OTP، ولم تتغير الصور القديمة أو الألوان والتخطيط أو المنطق التجاري.
